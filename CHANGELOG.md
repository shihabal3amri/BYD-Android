# BYD Android 9.16.1 · Walk-up Unlock v2.1

## English

Public release of the localized BYD Android app. Download the APK below or use the download page.

- BYD 9.16.1 with English, Arabic and Russian localization.
- Walk-up Unlock v2.1 with a modern interface, background detection and distance calibration.
- Compatibility improvements for Bluetooth keys with changing radio addresses and Samsung detection setup.
- Surround View improvements: old camera requests cannot interrupt a new session, with limited automatic recovery for temporary startup failures.
- Customizable bottom tabs and the existing battery-conscious detection design.

Already using a compatible build from this project? Install the update over it. If you have the original BYD app, uninstall it first.

Using the original BYD app? Uninstall it before installing this APK because the signing keys differ. Uninstalling removes its local data; you may need to sign in and set up your Bluetooth key again.

## Русский

Публичный релиз локализованного приложения BYD для Android. Скачайте APK ниже или на странице загрузки.

- BYD 9.16.1 с русской, английской и арабской локализацией.
- Вход при приближении v2.1: современный интерфейс, фоновое обнаружение и калибровка расстояний.
- Улучшена совместимость с Bluetooth-ключами с меняющимся адресом и настройка обнаружения на Samsung.
- Улучшен круговой обзор: старый запрос больше не прерывает новую сессию камеры; добавлены ограниченные автоматические повторы при временном сбое запуска.
- Настройка вкладок нижней панели и прежняя экономичная схема обнаружения.

Если у вас уже стоит совместимая сборка этого проекта, установите обновление поверх неё. Оригинальное приложение BYD сначала нужно удалить.

Оригинальное приложение BYD нужно удалить перед установкой APK: ключи подписи отличаются. При удалении стираются локальные данные; возможно, потребуется снова войти и настроить Bluetooth-ключ.
